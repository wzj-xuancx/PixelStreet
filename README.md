# PixelStreet · Beta

**桌面底部的一条像素商业街：经营小店、陪伴伙伴、制作装备，再独自或与好友出门探索。**

> **当前是开发中的 Beta，游戏代码版本为 0.19.0，不是正式发布版。** 玩法、数值、界面和存档格式仍可能调整。请使用独立试玩档，不要把重要进度作为唯一副本。仓库不包含玩家存档、安装包或开发者个人环境。

[本轮与历史更新](CHANGELOG.md) · [后续开发计划](ROADMAP.md) · [参与共建](CONTRIBUTING.md) · [资源体积与优化](docs/assets-size-report.md) · [实际验证范围](docs/verification.md)

## 已有内容

- **低干扰桌面底座**：常驻像素街道、五档高度、隐藏与托盘恢复；原有入口保持不变。
- **经营与制作**：补给商店、炼金工坊、原料、配方、NPC 售卖、经营安排和委托。
- **悠游营地**：伙伴、培养、花圃、料理、建设、遗物与收藏。
- **背包与配装**：人物六槽、宠物三槽，以及材料、装备、补给的制作与穿戴。
- **底部野外**：两关探索、采矿、手动／刷材料／自动推关，三种怪材、机制装备和裂晶守卫。
- **好友共斗**：2–4 人，共享怪物，各自结算材料；首发连接范围是局域网或玩家已有的私有组网。
- **成就与纪念**：现有星灯、精通和野外纪念。实体攀塔、战力玩法与更深入的挑战设计仍在计划中。

### 原双门的含义

| 入口 | 去向 |
|---|---|
| 地牢之门 | 原鼠标悠游营地：伙伴、培养、秘境、花圃、工坊等 |
| 远征之门 | 原远征整备／挂机；单人野外与组队野外在该页面内 |

新增内容不能把原双门改成别的玩法，也不能为了放入功能扩大底部街景。

## 开发环境

- **Node.js >= 22.12.0**，使用与 Node 配套的 npm；锁文件为 v3。
- Electron **44.5.1**、TypeScript **5.9.3**、PixiJS **8.22.0**、esbuild **0.25.12**。
- 首选开发／试玩平台：**macOS Apple Silicon**。Windows、Intel Mac 与其他系统未完成发行验收。
- 依赖使用 `package-lock.json` 中的精确版本，不提交 `node_modules/`。

在全新克隆的目录中：

```bash
npm ci
npm run typecheck
npm run build
npm test
```

`npm ci` 首次需要下载依赖和 Electron，不保证离线可用。**不要在指向其他项目的共享 `node_modules` 链接上执行安装或升级。**

### 安全试玩（macOS）

构建后运行：

```bash
node scripts/launch-isolated.mjs
```

脚本每次创建一个带标记的独立试玩目录，并在终端打印路径；退出后保留该目录，不读取或删除正式存档。这个辅助脚本当前使用 macOS Electron 路径。

```bash
# 以下命令使用默认进度目录，不用于隔离自动测试
npm start
npm run dev
```

默认进度目录名为 `PixelStreetCamp`。0.19.0 使用 schema8；合法旧 v7 升级前会创建原字节备份。回退旧版必须使用升级前备份，不要将新版存档直接交给旧版。

### 构建应用

```bash
# macOS Apple Silicon：构建一个独立 App，拒绝覆盖已有同名产物
npm run release:mac
```

这需要 macOS、Apple 的签名工具及当前平台的 Electron 运行时。当前签名方案是本地 ad-hoc，**未 Apple 公证**。已有 Windows 打包配置不代表 Windows 已可发行。安装包与源码归档应放入 GitHub Releases，不提交到源码仓库。

## Beta 的已知边界

- 软件层测试不能证明真实物理鼠标、中文输入法、透明点击穿透、系统合成、多显示器 DPI 或实际高刷表现。
- 0.19.0 有本机软件和同机多端测试记录，但**真实两台设备的 LAN 联机仍待验证**；不宣称公网自动穿透。
- 商店打开焦点、双门持续动画、按钮与背景的融合、野外挑战文字等反馈已列入 [ROADMAP](ROADMAP.md)，不在本轮假称已修复。
- 成就之塔重构、战力系统、开发者满资源按钮尚未实现；具体规则仍可讨论。
- 本地存档可修改，不提供公共服反作弊、认证排行、交易或云存档。

## 仓库结构

```text
apps/                  桌面主进程、renderer、Worker 与独立服务器原型
packages/              协议、内容与可测试的玩法核心
assets/                运行素材、必要来源与优化清单
vendor/                第三方原始素材、图标及可复现来源
licenses/              随源码与应用分发的第三方许可
scripts/               构建、隔离启动、资源与发版检查
tests/                 逻辑、故障、网络与原生测试代码
docs/                  开发说明、必要测试基线与资源审计
```

不包含依赖、App、DMG、安装 ZIP、构建输出、玩家进度、内部会话或历史截图／验收日志。少量 `vendor/*.zip` 是第三方素材原包，不是游戏安装包，不应一概删除。

## 共建方式

使用短功能分支和 Pull Request，描述修改、测试结果及未验证项。游戏逻辑、视觉稿与资源优化尽量分开提交，避免两位贡献者同时大改同一个场景文件。详细步骤见 [CONTRIBUTING.md](CONTRIBUTING.md)。
