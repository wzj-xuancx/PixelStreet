# 0.12.0 营地生活美术

由本轮用户授权的内置 image_gen 生成，原始输出保留。逐文件源路径、尺寸、PNG 类型与 SHA-256 见 files.json；所有提示词保留在同目录。没有使用 Python 或程序修改图像像素，运行时通过 CSS 取图集帧。

- village-square.png：建设广场的三个真实可点击地块背景。
- projects.png：列为茶座、温室、集市；行为木架、半成品、建成。图片随实际建设阶段切换。
- regulars.png：三位常客头像，上排从左到右矿工、采药人、旅行商人。RGBA 背景含透明像素；预览工具的彩色合成底不代表游戏中的实体底色。
- life-objects.png：九位伙伴的生活道具，茶席、园艺和游记也作为直接交互目标。
- keepsakes.png：按行排列三位常客各三件纪念物，与九个实际赠礼逐一对应。

regulars-source.png 保留生成源；regulars-cutout-attempt.png 是未采用的背景移除尝试。最终头像沿用原图。旧版下排三件道具的 CSS 安全采样为 300% × 235%，避免上排人物越过几何中线的残边；最终赠礼使用独立九格 keepsakes.png。

这些是静态绘画资源。人物轻微活动、选中高亮、实际点击目标和经营状态由游戏代码驱动；切去工作应用后停止场景动画，经济时间仍按原规则补算。
